# ContributorOps v0.1.0 — Public source release

ContributorOps is an open-source workflow for discovering worthwhile GitHub issues, preparing reviewable changes, applying bounded authorization checks, and turning completed contributions into verifiable career proof.

## Explore the project

- [Try the no-token browser walkthrough](https://ankitparekh007.github.io/contributorOps/#/demo). Its issue scenarios and scores are **fictional examples**.
- [Run the actual React + Express app](https://ankitparekh007.github.io/contributorOps/#/try) locally or in GitHub Codespaces. Demo mode requires no personal GitHub token.
- [Read a real upstream merged contribution case study](https://github.com/AnkitParekh007/contributorOps/blob/main/docs/case-study-floating-ui-3494.md): [Floating UI PR #3494](https://github.com/floating-ui/floating-ui/pull/3494) was merged October 26, 2026. The PR discloses ContributorOps-assisted preparation and constrained safety checks.
- [Contribute a focused change](https://github.com/AnkitParekh007/contributorOps/blob/main/CONTRIBUTING.md) or open workflow feedback.

## Engineering and trust

The source includes interactive action-scoped approvals, a separately authorized exact-patch execution queue, policy/duplicate checks, API/Web/Site builds, security testing, Lighthouse budgets, and a public growth attribution model. The hourly radar uses a safe read-only discovery fallback if the owner's custom GitHub credential is missing or rejected; externally writable operations remain opt-in and independently gated.

## Known limits

- **Not a hosted multi-user production SaaS**. Hosted accounts, user OAuth and billing are not launched.
- The browser walkthrough is not proof of a successful real-world contribution, which is why the upstream PR case study is linked separately.
- A merged upstream PR is one independently verifiable outcome, **not** a success rate, hiring guarantee or customer adoption figure.
- GitHub Actions secret rotation, fork permissions and optional repository settings must be configured by the operator.
- This is a **source-code release**; no signed desktop binaries or hosted service are included.

## Developer start

Node.js 20+ and npm 10+:

```bash
git clone https://github.com/AnkitParekh007/contributorOps.git
cd contributorOps
npm ci
npm run dev
```

Inspect [README](https://github.com/AnkitParekh007/contributorOps), [security model](https://github.com/AnkitParekh007/contributorOps/blob/main/docs/security-model.md), [roadmap](https://github.com/AnkitParekh007/contributorOps/blob/main/docs/roadmap.md) and the GitHub Actions validation evidence before enabling any write-capable automation.
