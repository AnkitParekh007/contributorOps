# ContributorOps roadmap

This roadmap distinguishes what is public and implemented from work that is still planned. **No milestone is proof of customer adoption or hosted production readiness.**

## Available now

- Public GitHub Pages website, documentation and fictional browser demo
- Local/Codespaces demo-safe React UI and Express API
- Role-aware issue discovery, planning and portfolio-proof flows
- Interactive action-scoped approval and a separate standing exact-patch authorization model
- Repository policy, duplicate, risk and quality checks
- Public launch and growth instrumentation, including Phase 9 campaign attribution
- CI, CodeQL and supply-chain/security checks with documented configuration limits

## Immediate reliability and contributor priorities

1. Recover hourly discovery from expired/invalid custom tokens without granting write permissions to the fallback; rotate the custom token before enabling authorized workspace writes.
2. Review incoming external contributions (especially draft [PR #19](https://github.com/AnkitParekh007/contributorOps/pull/19)); keep starter issues actionable.
3. Provide an approachable first-contribution walkthrough and real screenshots of the running app.
4. Keep release notes current and verify primary demo/Codespaces routes on desktop and mobile.
5. Track **unique visitors → demo evaluation → source/clones → contributor questions/PRs**, using private GitHub Traffic and optional analytics rather than inventing conversion rates.

## Next product iteration

- Make live GitHub issue selection easier for individual developers, with clear token scope and onboarding.
- Add deterministic contribution-quality examples and guided first-workflow diagnostics.
- Improve accessibility, loading/empty states and documented first-contributor test paths.
- Publish evidence-backed end-to-end case studies, distinguishing merged PRs from pending submissions.
- Iterate against actual feedback from developers and maintainers.

## Longer-term exploration (not shipped)

- Per-user GitHub OAuth, production multi-user database and hosted accounts
- Team/cohort management and shared contribution workspaces
- Billing/payments and institutional offerings
- Additional maintainer-facing review analytics
