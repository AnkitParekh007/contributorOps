# Monetization Plan

## Pricing model

### Free

- Basic issue discovery
- 3 contribution plans per week
- Manual portfolio tracker
- Basic docs

### Pro

- Daily contribution plans
- Job-matched issue finder
- PR quality checker
- Portfolio page
- Resume bullets
- LinkedIn drafts

### Career

- Everything in Pro
- Interview story generator
- Recruiter outreach drafts
- GitHub profile audit
- Advanced proof-of-work exports
- Weekly career report

### Team

- Team contribution dashboard
- Bootcamp/team tracking
- Shared repo radar
- Team portfolio reports
- Admin controls
- Priority roadmap input

## Fast monetization features

The product is already structured around monetization-ready surfaces:

- pricing page
- feature flags
- public portfolio page
- resume export
- LinkedIn drafts
- interview story generator
- recruiter proof surfaces

## Payments

No real payment processing is implemented yet.

The code should remain ready for:

- Stripe
- Lemon Squeezy

## Implementation approach

Billing is currently mocked and local-first. That keeps the product explorable, demoable, and GitHub Pages friendly while preserving future SaaS packaging options.
