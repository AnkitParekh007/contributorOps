# GitHub social-preview setup

The public site serves `apps/site/public/og-image.png`, a **1200 × 630 PNG** exported from the repository's existing `og-image.svg` artwork. The site now references this PNG in Open Graph and Twitter/X metadata.

GitHub's **native repository social preview** is a separate account-level setting that cannot be changed by committing a file. To activate it:

1. Download or locate [`apps/site/public/og-image.png`](https://github.com/AnkitParekh007/contributorOps/blob/main/apps/site/public/og-image.png).
2. Open the repository's **Settings → General → Social preview**.
3. Upload the PNG and save.
4. Inspect a shared repository link, plus public-site links to the browser demo and verified case study.
5. Re-upload if you materially change product positioning or artwork.

The PNG alone does **not** prove the GitHub repository's social-preview setting was saved. Do not mark the item complete until verified on GitHub.
